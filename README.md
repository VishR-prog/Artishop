# Artishop

A responsive, single-file storefront concept for handmade goods from makers in Bangalore. It includes product search, a local-storage basket, maker profiles, and a demo donation form. No checkout or payment processing is connected.

## Run locally

Open `Artishop.html` in a modern browser. No build step or dependencies are required. The Google Fonts import is optional; the page falls back to sans-serif fonts if it cannot load.

## Demo notes

Maker profiles and product listings are illustrative. Basket data is stored in the browser's local storage; donations do not take or transmit payment.
